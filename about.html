About VitalConnect

VitalConnect is a responsive community wellness website designed as an IT499 capstone project and built for static deployment.

Project Purpose

VitalConnect addresses the need for a user-friendly platform where members can connect through wellness tracking, prayer support, resource sharing, and community assistance. The solution demonstrates front-end architecture, responsive design, client-side validation, and persistent browser storage.

Technical Approach

The website uses HTML, CSS, JavaScript, JSON seed files, and LocalStorage to replace traditional database services on a restricted school hosting environment. This approach supports usability, maintainability, and straightforward deployment.
