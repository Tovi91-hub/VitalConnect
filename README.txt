VitalConnect Deployment Notes

1. Upload the entire VitalConnect folder contents to your school hosting space.
2. Ensure index.html is placed in the site root.
3. Keep the css, js, data, and assets folders in the same relative structure.
4. Login demo accounts:
   - demo@vitalconnect.com / Password123!
   - admin@vitalconnect.com / Admin123!
5. Registration creates a new browser-stored account using LocalStorage.
6. If you want a clean reset for demonstrations, clear LocalStorage in the browser.
